# rabbit-run

토끼가 장애물을 뛰어넘고 당근을 모으는 브라우저 달리기 게임입니다. 공개 웹앱 버전 0.5에는 A안 토끼 디자인과 달리기·점프·착지·대기·충돌 애니메이션이 적용되어 있습니다.

## 실행

별도의 빌드나 패키지 설치가 필요하지 않습니다. 저장소를 내려받고 `bunny-run/dist/index.html`을 브라우저에서 열면 됩니다.

로컬 웹 서버로 실행하려면 저장소 루트에서 다음 명령을 실행하세요.

```sh
python -m http.server 4173 --directory bunny-run/dist
```

브라우저에서 `http://localhost:4173`을 엽니다. 외부 글꼴이나 런타임 의존성 없이 시스템 글꼴로 실행합니다.

## 조작

- Space / 위쪽 방향키 / 화면 터치: 점프
- P: 일시정지 및 계속하기
- Enter: 시작 및 재시작
- 화면 상단 버튼: 소리 켜기/끄기

장애물에 부딪히면 게임이 종료됩니다. 최고 거리는 해당 브라우저의 로컬 저장소에 보관됩니다.

## 파일

- `bunny-run/dist/index.html`: 게임 화면
- `bunny-run/dist/style.css`: 반응형 스타일
- `bunny-run/dist/game.js`: 게임 루프, 점프 물리, 충돌, 점수
- `bunny-run/dist/bunny-sprites.js`: A안 스프라이트와 상태별 애니메이션
- `bunny-run/dist/assets/bunny-a-atlas.png`: 투명 배경 12자세 스프라이트 시트
- `bunny-a-production.txt`: 이미지 제작 도구와 프롬프트
- `check-game.cjs`: DOM·Canvas를 모의한 게임 및 애니메이션 검사

## 검사

Node.js가 설치된 환경에서 저장소 루트에서 실행합니다.

```sh
node check-game.cjs
```

점프·착지, 일시정지, 당근 수집, 충돌, 재시작, 스프라이트 선택과 좌표를 검사합니다. 실제 브라우저의 시각 품질·키보드·터치 검증은 별도로 필요합니다.

## 공개 배포 및 설치형 웹앱 (PWA)

https://bunny-meadow-run-sm-1121.snugbrink3.chatgpt.site

## 영구 특성과 높은 당근 길 (v0.5)

달리기가 끝나면 `floor(이동 거리 / 3) + 당근 수` 코인을 지급합니다. 메인 화면의 **특성 상점**에서 이동속도·점프 높이를 각각 최대 5레벨까지 강화합니다. 각 레벨은 해당 능력을 10%씩 높이며 최대 +50%입니다. 효과는 선택한 레벨에 따라 한 판 내내 자동으로 적용됩니다.

| 구매할 레벨 | 필요 코인 | 적용 증가량 |
| --- | ---: | ---: |
| 1 | 1,000 | +10% |
| 2 | 2,000 | +20% |
| 3 | 4,000 | +30% |
| 4 | 8,000 | +40% |
| 5 | 16,000 | +50% |

메인 화면에서 구매한 최고 레벨 이하의 **0~5레벨**을 능력별로 선택한 뒤 시작합니다. 선택한 레벨은 저장되며, 한 판이 시작되면 고정됩니다. 일시정지 중 강화하더라도 현재 판에는 반영되지 않고 다음 시작부터 적용됩니다. 코인과 성장 정보는 현재 브라우저에 저장되며 기기 간 동기화되지 않습니다.

기존 물약은 보유 개수 × 1,000코인으로 **한 번만 자동 환불**합니다. 기존 코인과 최고 기록은 유지됩니다. 소비형 아이템과 10초 버프는 사용하지 않습니다.

약 80m부터 높은 당근 길이 등장하며 이후 반복됩니다. 길의 높이는 점프 2레벨의 최대 높이보다 높고 3레벨의 최대 높이보다 낮습니다. 제때 점프하면 **점프 Lv.3 이상**으로 발판 위에 착지하고 당근을 모을 수 있습니다. 낮은 점프 레벨은 아래쪽 평지를 지나갈 수 있습니다. 발판 위에서 다시 점프하거나 끝에서 아래로 내려올 수 있습니다.

`bunny-run/dist/terrain.js`는 고도·중력·발판 착지를 처리합니다. `node check-shop.cjs`로 영구 성장·비용·저장·환불과 레벨별 발판 도달 및 실제 게임 연결을 검사합니다. `node check-game.cjs`, `node check-pwa.cjs`로 기본 게임 및 오프라인 동작을 검사합니다. 실제 기기 화면·터치 검증은 별도로 필요합니다.

설치한 이전 버전은 온라인으로 열고 **업데이트**를 눌러 새 특성 버전을 받으세요.
