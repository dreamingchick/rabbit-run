# 버니 런 설치와 오프라인 플레이

공개 배포: https://bunny-meadow-run-sm-1121.snugbrink3.chatgpt.site

## 설치

- Android: Chrome에서 링크를 열고 게임의 **앱 설치** 버튼 또는 브라우저 메뉴의 **홈 화면에 추가**를 선택합니다.
- Windows / macOS: Chrome 또는 Edge에서 링크를 열고 **앱 설치** 버튼이나 주소창의 설치 아이콘을 사용합니다.
- iPhone / iPad: Safari에서 링크를 열고 **공유 → 홈 화면에 추가**를 선택합니다.
- 다른 앱 안의 브라우저에서는 설치 메뉴가 없을 수 있습니다. 기본 브라우저로 열어주세요.

## 오프라인

처음에는 인터넷에 연결해 페이지를 열고 **오프라인 플레이 준비 완료** 표시를 기다립니다. 이후 설치 아이콘이나 같은 주소에서 인터넷 없이 플레이할 수 있습니다. 브라우저가 사이트 데이터를 삭제하면 다시 연결해 게임을 저장해야 합니다. 최고 기록은 브라우저의 로컬 저장소에 저장됩니다.

## 업데이트

온라인으로 앱을 다시 열면 새 버전을 확인합니다. **새 버전이 준비됐어요** 안내에서 **업데이트**를 누르면 게임을 일시정지하고 새 버전으로 다시 엽니다. 진행 중인 달리기는 초기화되며 최고 기록은 유지됩니다.

## 개발

정적 루트는 `dist/`입니다. HTTPS 또는 localhost에서 서비스 워커와 설치 기능이 동작합니다. `file://`로 직접 연 파일에서는 PWA 기능을 사용할 수 없습니다.

파일을 변경할 때는 `dist/sw.js`의 캐시 이름도 갱신합니다. 모든 게임 파일을 먼저 저장한 새 서비스 워커가 준비된 뒤에만 사용자가 업데이트할 수 있어, 오프라인에서 누락된 스프라이트나 스크립트를 참조하지 않습니다. 외부 글꼴과 외부 런타임 의존성이 없습니다.

검사(저장소 루트): `node check-game.cjs` 및 `node check-pwa.cjs`.

오프라인 캐시·설치 이벤트 검사는 모의 환경에서 수행했습니다. 실제 OS 설치·홈 화면 실행·모바일 화면 검증은 별도로 필요합니다.
